# Plot photos

Drop a close-up photo of a plot in here, named after the plot in lower case:

    b2.jpeg   ->  plot B2
    u17.jpg   ->  plot U17
    n5.png    ->  plot N5

That is the whole job. Nothing else needs editing: the build picks up every
file in this folder and PALMS uses it wherever that plot's map is shown —
Settings, the area picker on Update Status, and the area map on the
Monitoring Board.

A photo of one plot on its own is far sharper than a crop out of the
whole-nursery aerial map, which is why it wins when present. A plot with no
file here falls back to that crop.

Photos uploaded through PALMS → Settings are NOT here. Those live in the
browser's own storage on the one device that uploaded them, so they never
reach anybody else's phone and are lost when that browser clears its data.
Putting the file in this folder is what makes it permanent and shared.

Keep them a sensible size — around 1600px wide is plenty. Every file here is
downloaded by every device that opens the module.
